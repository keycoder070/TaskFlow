# TaskFlow

A simple and responsive Task Management App built with React.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Total tasks counter
- Completed and pending task counter
- Save tasks using Local Storage
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- Vite

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL in your browser.
